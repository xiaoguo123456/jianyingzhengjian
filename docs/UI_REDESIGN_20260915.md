# 首页改版验收记录

日期：2026-09-15。

## 已完成

- 证件照、职业照、写真、头像和我的页面使用统一的纯蓝主色、中性底色与分级字重。
- 证件照压缩宣传区、隐藏首页重复像素参数、改为紧凑用途列表。
- 职业照使用独立主视觉与两列模板，写真使用环境人像主视觉与两列精选，推荐数据按模板 ID 去重。
- 两张专题封面按实际展示比例裁切，保留完整面部；专题列表按实际成员展示。
- 我的页面展示最近作品并支持分类筛选，补齐加载、失败与空状态；原图入口更名为原始照片。
- 统一规格、模板等组件的 `select` 事件，避免 uni-app 原生 `tap` 事件冲突。
- H5 弹层使用高于系统底部导航的层级，取消操作不再被遮挡。
- 使用指定接口的 `gpt-image-2.5` 生成 20 张独立样片，优化后同步到客户端和后台种子目录。密钥未写入项目。
